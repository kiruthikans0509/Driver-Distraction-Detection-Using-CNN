7. ROOT CAUSE ANALYSIS
===============================================================================

BOTH models catastrophically fail on Friend 5 (24.51% vs 27.91%).
This confirms the hypothesis that the problem is NOT model-specific.

Evidence:
1. V3 (trained on session2 only) fails catastrophically on Friend 5 (24.51%)
2. V4 (trained on session2 + session3_raw) also fails catastrophically (27.91%)
3. Both models show identical failure patterns:
   - Complete failure on Operating radio (c5) and Reaching behind (c7)
   - Massive safe driving over-prediction
   - Poor performance on Hair/makeup (c8) and Talking to passenger (c9)

Conclusion:
- The failure is caused by the FUNDAMENTAL DIFFICULTY of session3_raw data
- Friend 5 is 100% session3_raw
- Neither model learned to generalize to session3_raw characteristics
- The visual differences identified earlier (34% brighter, 19% lower contrast) are likely the primary cause
- This is NOT a V4-specific training problem
- This is NOT a model architecture problem
- This is a DATASET DISTRIBUTION problem

- Neither model was trained to be robust to these variations
